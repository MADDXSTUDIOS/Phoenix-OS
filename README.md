# Phoenix OS

A Windows-style desktop operating system for CC:Tweaked advanced computers (Minecraft 1.21.1).

**Phoenix OS is under development and not ready to install yet.** Running the installer
shows a notice and installs nothing:

```
wget run https://raw.githubusercontent.com/MADDXSTUDIOS/Phoenix-OS/main/install.lua
```

Work in progress lives on the [`dev`](https://github.com/MADDXSTUDIOS/Phoenix-OS/tree/dev) branch.
Development builds are unfinished and may break; to try one anyway:

```
wget run https://raw.githubusercontent.com/MADDXSTUDIOS/Phoenix-OS/main/install.lua dev
```
